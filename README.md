# Loper

**The easiest code editor on the market — a gift from [Nomad Code Labs](https://nmdcd.com/loper).**

Quick, easy viewing and editing of `.env`, Markdown, JSON, YAML, TOML, code and more, with colors that make every key and value easy to spot.

This repository only hosts Loper's release builds and its update feed. Download the latest version from [nmdcd.com/loper](https://nmdcd.com/loper) or the [Releases](../../releases/latest) page.
